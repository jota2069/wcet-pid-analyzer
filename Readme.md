# WCET PID Analyzer

> Анализатор лучшего и худшего времени выполнения шага ПИД-регулятора

---

## Описание ✍️😴

**WCET PID Analyzer** - приложение на Python для оценки временных характеристик одного шага ПИД-регулятора.

Программа рассчитывает:

- лучшее время выполнения `BCET`
- худшее время выполнения `WCET`
- коэффициент недетерминизма `WCET / BCET`
- вклад памяти в худшее время выполнения
- вклад ветвлений в худшее время выполнения
- соблюдение заданного дедлайна.

В качестве анализируемого фрагмента используется **шаг ПИД-регулятора**:

- чтение уставки
- чтение текущего значения
- вычисление ошибки
- вычисление пропорциональной составляющей
- обновление интегральной суммы
- вычисление дифференциальной составляющей
- суммирование управляющего сигнала
- ограничение управляющего сигнала
- запись команды на привод.

## Входные данные 📄

### `data/processor.json`

```json
{
  "base_cost": 2,
  "cache_miss_penalty": 12,
  "branch_miss_penalty": 6,
  "deadline": 100
}
```

где:

- `base_cost` - базовая стоимость одной операции в тактах
- `cache_miss_penalty` - штраф за одно обращение к памяти в худшем случае
- `branch_miss_penalty` - штраф за одно ветвление в худшем случае
- `deadline` - максимально допустимое время выполнения фрагмента.

### `data/fragment.json`

Для каждой операции задаются:

- `name` - имя операции
- `type` - тип операции
- `memory_accesses` - количество обращений к памяти
- `branches` - количество ветвлений.

Текущий набор операций:

| Операция | Тип | Память | Ветвления |
|---|---|---:|---:|
| Чтение уставки | чтение | 1 | 0 |
| Чтение текущего значения | чтение | 1 | 0 |
| Вычисление ошибки | арифметика | 0 | 0 |
| Пропорциональная составляющая | арифметика | 0 | 0 |
| Обновление интегральной суммы | состояние | 1 | 0 |
| Дифференциальная составляющая | состояние | 1 | 0 |
| Суммирование управляющего сигнала | арифметика | 0 | 0 |
| Ограничение управляющего сигнала | ветвление | 0 | 2 |
| Запись команды на привод | запись | 1 | 0 |

## Расчёты 📐

Лучшее время выполнения одной операции:

```text
BCET_op = base_cost
```

Худшее время выполнения одной операции:

```text
WCET_op =
base_cost
+ memory_accesses * cache_miss_penalty
+ branches * branch_miss_penalty
```

Суммарное лучшее время:

```text
BCET = Σ BCET_op
```

Суммарное худшее время:

```text
WCET = Σ WCET_op
```

Коэффициент недетерминизма:

```text
K = WCET / BCET
```

Проверка дедлайна:

```text
WCET <= deadline
```

## Как запустить 🚀

### Требования

- Python 3.10+
- Git

### Клонирование репозитория

```bash
git clone https://github.com/jota2069/wcet-pid-analyzer.git
cd wcet-pid-analyzer
```

### Создание виртуального окружения

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Запуск консольной версии

```bash
python -m src.main
```

### Запуск графического интерфейса

```bash
python -m src.gui
```

### Запуск тестов

```bash
python -m pytest
```
